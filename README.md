# Ужинчик — Битва блюд и десерты

Обновлённая версия на основе **nastik-dinner-neutral**, без доставки, блока «Ужин за 300 рублей» и раздела «Мои рецепты».

## Что осталось

- **57 исходных рецептов** в `recipes.js` с ингредиентами и текстовыми инструкциями.
- **12 дополнительных рецептов десертов** в `desserts.js`. Всего 69 блюд, включая 13 десертов.
- **Битва блюд** — шесть раундов выбора между двумя блюдами, затем открывается подробный рецепт победителя.
- **А что на сладкое?** — библиотека десертов со случайным выбором.
- Подбор по имеющимся продуктам, обычная рулетка, общий каталог, избранное и список покупок.
- **Пасхалка в рулетке** — отдельная кнопка «В пизду всё, заебал Максим... ДАВАЙ ЕБАНЁМ ПИВА!». Показывает мемный результат и позволяет вернуться к обычной рулетке; ничего не заказывает.

## Видео

В `nastik-dinner-neutral` не было встроенных проверенных видео ко всем блюдам. Пошаговые текстовые инструкции сохранены. В этой сборке нет раздела пользовательских рецептов, а значит и поля для добавления своих YouTube-ссылок. Ни один ролик не был придуман или подставлен случайно.

## Загрузка в GitHub Pages

1. Распакуй ZIP.
2. Открой репозиторий `https://github.com/theyhateadii-bit/nastikhochetkushac` и перейди на ветку `main`.
3. Загрузи файлы из распакованного архива через **Add file → Upload files**, заменив одноимённые файлы, и нажми **Commit changes**.
4. Открой `https://theyhateadii-bit.github.io/nastikhochetkushac/` и обнови страницу через `Ctrl + Shift + R`.

Все пути относительные; сайт работает без сервера, API-ключей и регистрации. Локальные данные старых удалённых разделов не очищаются кодом: если захочешь вернуть их в другой версии, они могут сохраниться в прежнем браузере.

## Файлы

- `index.html` — интерфейс.
- `styles.css`, `app.js`, `recipes.js`, `favicon.svg` — базовые файлы.
- `desserts.js` — дополнительные десерты.
- `features.js`, `features.css` — битва и витрина десертов.
- `.nojekyll` — для GitHub Pages.
