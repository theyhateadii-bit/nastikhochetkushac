# Ужинчик — версия с битвой блюд, бюджетом, десертами и своими рецептами

Полностью статический сайт на HTML, CSS и JavaScript. Подходит для бесплатного GitHub Pages; без сервера, оплаты, API-ключей и регистрации.

## Что внутри

- **57 исходных рецептов** из `nastik-dinner-neutral`: файл `recipes.js` сохранён без изменений, вместе с составами и пошаговыми инструкциями.
- **12 новых десертов** в `desserts.js`: синнабоны, клюквенный хлеб, шоколадный брауни и другие. Всего **69 рецептов**, из них 13 десертов.
- **Битва блюд**: 6 раундов выбора между двумя блюдами, где победитель остаётся. В финале кнопка открытия рецепта. В битве участвуют и собственные несладкие рецепты.
- **Ужин за 300 рублей**: подбор по ориентировочной стоимости ингредиентов на 1, 2, 3 или 4 порции; кнопки бюджета 200, 300, 500 ₽. 70 исходных цен продуктов редактируются прямо в интерфейсе и сохраняются локально.
- **А что на сладкое?**: отдельная библиотека десертов и кнопка случайного десерта; карточка открывает тот же подробный рецепт, что и основная библиотека.
- **Мои рецепты**: можно создать, изменить и удалить свой рецепт; добавить ингредиенты, шаги, сложность, порции, примерную стоимость и ссылку на YouTube-видео. Такие ролики отображаются во встроенном плеере. Собственные несладкие рецепты с указанной стоимостью можно найти и в бюджетном подборе. Есть экспорт и импорт резервных копий JSON.
- Старые функции не удалены: подбор по домашним продуктам, обычная рулетка, каталог, избранное, отметка «приготовлено», список покупок.

### Важное про видео

**В исходном `nastik-dinner-neutral` не было видеороликов или встроенных плееров.** Исходные текстовые инструкции сохранены целиком. В разделе «Мои рецепты» можно прикрепить реальную ссылку YouTube, и сайт покажет плеер внутри собственного рецепта. Конкретные видео для всех стандартных 69 блюд здесь не подобраны. Случайные или непроверенные ссылки не подставляются.

### Важное про цены

Цены в бюджете — **только демонстрационные ориентиры**, а не онлайн-цены магазинов Новосибирска. Рассчитывается приблизительная стоимость использованного количества основных ингредиентов, а не общая стоимость покупки полных упаковок. Фактическая сумма в магазине может быть больше. В бюджетном режиме пользователь может вручную изменить цены, а рецепты без полной оценки исключаются из бюджетного списка. Соль, вода, масло для жарки и необязательные продукты не включаются в оценку.

## Как обновить сайт в GitHub

1. Распаковать ZIP на компьютере.
2. Открыть репозиторий https://github.com/theyhateadii-bit/nastikhochetkushac .
3. На ветке `main` нажать `Add file` → `Upload files`.
4. Перетащить **содержимое** распакованной папки в корень репозитория (рядом с `index.html`). Заменить существующие одноимённые файлы. Обязательно загрузить новые `desserts.js`, `features.js`, `features.css`.
5. Нажать `Commit changes`.
6. После публикации открыть https://theyhateadii-bit.github.io/nastikhochetkushac/ и обновить страницу через `Ctrl + Shift + R` или в приватном окне.

Весь сайт остаётся на прежнем адресе. **Раздела заказов еды и доставки нет.**

## Хранение данных

Продукты, покупки, избранное и отметки готовки сохраняются в `localStorage` браузера (`nastik-dinner-v1`). Свои рецепты сохраняются отдельно (`nastik-my-recipes-v1`), пользовательские цены — в `nastik-budget-prices-v1`.

Информация хранится **на конкретном устройстве и в конкретном браузере**. Между телефонами и компьютерами автоматически не синхронизируется. При очистке данных сайта личные рецепты могут пропасть — для переноса или резервирования в разделе «Мои рецепты» есть кнопки «Сохранить копию» и «Загрузить копию».

## Файлы

- `index.html` — страницы, разметка новых разделов.
- `styles.css` — оригинальные стили.
- `features.css` — стили новых разделов и мобильная адаптация.
- `recipes.js` — **оригинальные 57 рецептов без изменений**.
- `desserts.js` — 12 новых десертов, которые добавляются к рецептам перед инициализацией сайта.
- `app.js` — оригинальная логика подбора рецептов, избранного и покупок.
- `features.js` — битва, бюджет, десерты и свои рецепты.
- `favicon.svg` — иконка.
- `.nojekyll` — GitHub Pages.

Все ссылки на скрипты относительные. Для раздачи сайта достаточно статического хостинга.
