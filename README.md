# Ужинчик — сайт для Настик

Красивый, полностью готовый сайт с **57 рецептами**, который работает на бесплатном **GitHub Pages**, без сборки, Node.js, базы данных или API-ключа.

## Как выложить на GitHub за 5 минут

1. Скачай архив `nastik-dinner-neutral-menu.zip` и **распакуй** его на компьютере.
2. Открой существующий репозиторий [theyhateadii-bit/nastikhochetkushac](https://github.com/theyhateadii-bit/nastikhochetkushac).
3. Открой новый репозиторий → **Add file → Upload files**.
4. Перетащи **все файлы из распакованной папки** в окно загрузки (не ZIP и не папку целиком). Замени одноимённые файлы, а новые `planner.js` и `planner.css` обязательно добавь. `index.html` должен лежать в корне репозитория.
5. Нажми **Commit changes**.
6. Открой **Settings → Pages** → в блоке **Build and deployment** выбери **Source: Deploy from a branch**.
7. Укажи **Branch: main**, **Folder: /(root)** и нажми **Save**.
8. Подожди несколько минут и открой **https://theyhateadii-bit.github.io/nastikhochetkushac/**. Обнови страницу через Ctrl+Shift+R, если видишь старую версию.
9. Отправь Настик ссылку.

Если GitHub не загружает `.nojekyll`, это не страшно — для этого проекта он необязателен.

**Официальная справка GitHub:** [как опубликовать сайт](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Возможности

- **По продуктам.** Можно ввести `курица, рис, лук` или просто фразой `у меня есть курица рис лук`. Сайт покажет блюда с имеющимися продуктами и варианты, где надо докупить 1–2 продукта или больше.
- **Что докупить.** В каждой карточке рецепта видно, чего не хватает; из подробного рецепта можно добавить недостающие ингредиенты в список покупок.
- **Советы.** Для каждого блюда есть идея, как сделать вкуснее, и с чем подать, чтобы ужин получился сытнее.
- **Рулетка.** Случайное блюдо с выбором сложности: легко / средне / сложно / все.
- **Мне лень готовить.** Случайный простой рецепт до 15 минут, в том числе можно отфильтровать только по имеющимся дома продуктам.
- **Что я сегодня хочу?** Подбор по желанию (сытное, лёгкое, суп, без мяса и т. д.) и доступному времени; выдаёт до трёх подходящих рецептов.
- **Меню на неделю.** Семь разных ужинов; можно сменить отдельный день, составить план заново или добавить недостающие продукты в покупки. Меню сохраняется в браузере.
- **Видео приготовления.** В каждой карточке есть ссылка на поиск русскоязычного видео конкретного блюда на YouTube. **Важно:** в исходной версии `nastik-dinner-neutral` не было подобранных и проверенных ссылок на 57 роликов. Поэтому программа **не выдаёт случайные ролики за проверенные и не встраивает неверные видео**. Если добавить проверенный YouTube ID в поле `videoId` рецепта, видео автоматически появится встроенным плеером.
- **Каталог.** Поиск рецептов, фильтрация по сложности и типу блюда.
- **Избранное.** Звёздочка сохраняет выбранные рецепты.
- **Приготовила!** Можно отмечать уже приготовленные блюда.
- **Покупки.** Можно вручную добавлять продукты, отмечать купленное и копировать список.
- **Под телефон.** Адаптивная мобильная версия, работает и с компьютера.

Избранное, меню на неделю, список покупок, отметки «приготовила» и текст продуктов сохраняются **в этом браузере на этом устройстве**. Они **не синхронизируются между разными телефонами, браузерами и устройствами**; очистка данных сайта может их удалить.

## Из чего состоит проект

| Файл | Назначение |
|---|---|
| `index.html` | Страницы и структура сайта |
| `styles.css` | Цвета, анимации и мобильный дизайн |
| `recipes.js` | Все 57 рецептов, ингредиенты, шаги и советы |
| `app.js` | Логика поиска, рулетки, избранного и покупок, ссылки на видео и плеер для проверенных videoId |
| `planner.js` | Лень готовить, подбор по настроению, меню на неделю |
| `planner.css` | Стили новых разделов, в том числе для телефона |
| `favicon.svg` | Иконка вкладки |
| `.nojekyll` | Опциональный файл для GitHub Pages |

## Как добавить свой рецепт

Открой `recipes.js`, найди `window.DINNER_RECIPES = [` и добавь новый `create({...}),` внутрь списка. Пример:

```javascript
create({
  id:'my-pasta',
  name:'Паста с сыром',
  emoji:'🍝',
  difficulty:'easy', // easy / medium / hard
  minutes:20,
  category:'hot', // hot / soup / salad / snack / breakfast / dessert
  description:'Очень вкусно и быстро!',
  ingredients:['макароны|200 г','сыр|70 г','?зелень|немного'],
  steps:['Отвари макароны.','Добавь сыр.','Перемешай и подавай.'],
  upgrade:'Щепотка базилика сделает аромат ярче.',
  pair:'Подавай со свежими овощами.'
}),
```

Символ `?` перед названием ингредиента означает **необязательный ингредиент**, который не требуется для готовности блюда.

Для персонализации названия, надписей и цветов можно редактировать `index.html` и `styles.css`.

## Важное про ИИ

Этот сайт сразу предлагает блюда **без нейросети**: он сравнивает введённые продукты с 57 подготовленными рецептами и показывает заранее составленные советы. Поэтому он работает бесплатно на одном GitHub Pages и не требует ничего настраивать. Он **не отправляет текст в ChatGPT** и не сочиняет новые рецепты за пределами каталога.

Для ответов **настоящего ChatGPT/OpenAI на любые продукты** потребуется отдельный защищённый backend (например, Cloudflare Workers или серверная функция), OpenAI API и его оплата. **Нельзя вставлять API-ключ в `app.js`, `index.html` или публичный репозиторий** — его смогут украсть. При желании реальный ИИ можно добавить второй версией без переделки всего сайта.

В рецептах предполагается, что вода, соль, перец и обычное растительное масло — базовые продукты. Ориентируйся на фактическую готовность мяса/рыбы, так как время зависит от размера кусков и техники.


## Если захочешь встроить проверенные видео

В `recipes.js` у нужного рецепта можно добавить `videoId:'XXXXXXXXXXX'` (11 символов после `v=` в ссылке YouTube). После обновления на GitHub в карточке появится встроенный YouTube-плеер. Видео не хранятся в архиве и требуют подключения к YouTube. Не стоит подставлять непроверенные ссылки: даже похожее название ролика не гарантирует совпадение ингредиентов и шагов.

## Что сохраняется и как устроена неделя

Меню на неделю хранится в `localStorage` текущего браузера и не синхронизируется между устройствами. Дни идут от понедельника до воскресенья; выбор не привязан к календарным датам. «Докупить продукты» учитывает список того, что указано в разделе «Что есть дома?». Повторяющиеся названия продуктов в списке покупок не дублируются, но количества из разных блюд не суммируются. Для точного расчёта количества открой рецепты и проверь порции.
